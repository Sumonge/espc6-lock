# PCB 版设计方案

把 `espc6-lock` 从「XIAO 开发板 + 杜邦线」做成一块可以**到手插上就用**的 PCB。

定位是**弱化版的官方 XIAO 扩展板**：官方扩展板有的（电池管理、屏幕座、按键），
把它那块用不上的（SD 卡、RTC、蜂鸣器、Grove 口）砍掉，把我们要的（舵机、
电池电量检测）加上。

> ⚠️ **本文全部是纸面设计，没有一个元件在实机上验证过。**
> 所有数值（电流、电容、线宽）都是按数据手册和常见做法估的。
> 打样前请自行复核，尤其是 §4 的电池部分和 §7 的顶针尺寸。

## 0. 这一版砍掉了什么

上一版方案（见 git 历史里的旧 `DESIGN.md`）是 12V 输入 + 电池备份的 UPS 架构，
带 buck、boost、ORing、板载充电、步进驱动。**那一版的前提已经全部作废**：

| 旧版的东西 | 为什么没了 |
|---|---|
| 12V 输入 + buck | 用户砍掉了电机。没有 12V 负载，就不需要 12V |
| 步进驱动 + StepStick 座 | 用户砍掉了电机 |
| 板载充电 IC（TP4056 等） | **XIAO 自己带充电**（SGM40567-4.2）。电池接到 XIAO 的 BAT 焊盘，充电白送 |
| 两路 5V 的 ORing + 理想二极管 | 只剩一路 5V 源（boost），没有第二个源可抢 |
| `VM_5V → XIAO 5V` 的防倒灌二极管 | 我们**根本不接 XIAO 的 5V 脚**了 |

**最大的简化不是省了几个元件，是省掉了「两个电源抢电流」这一整类问题。**
旧版 §3.3（5.15V/5.00V 压差选主）、§3.4（理想二极管不能省成肖特基）、
§3.5（buck-boost 备选）三节现在整节不存在——前提没了。

> 如果将来要把电机加回来，那三节会**原样复活**（电机要 12V，就又要有第二路
> 输入、又要 ORing）。到时候翻 git 历史，别重新发明。

## 1. 需求

| 项 | 决定 | 来源 |
|---|---|---|
| 供电 | **只靠 1S 锂电池**（3.0~4.2V），USB-C 充电 | 用户选定 |
| 电池管理 | **用 XIAO 自带的充电电路**，板上不做充电 IC | 用户选定 |
| 电池接入方式 | **两根顶针顶住 XIAO 背面 BAT 焊盘**，不焊线 | 用户选定（方案甲） |
| 主控 | 保留 XIAO ESP32C6，**做插座**插上去 | 用户选定 |
| 舵机 | 保留，驱动锁舌。**唯一需要升压的负载** | 用户选定 |
| 电机 / 步进 | **不做** | 用户选定 |
| 摄像头 | **不做**。ESP32-C6 无并口摄像头接口，只有 SPI | 见 §10 |
| 电量检测 | **电阻分压进 ADC**，不用电量计芯片 | 用户选定 |

## 2. 负载电流预算

**这是选 boost 的唯一依据。**

| 负载 | 典型 | 峰值 | 说明 |
|---|---|---|---|
| XIAO ESP32C6 | 80 mA | 350 mA | WiFi 发射瞬间 |
| OLED | 15 mA | 20 mA | 挂在 XIAO 的 3V3 上 |
| 舵机（SG90/MG90S 级） | 150 mA | **1.0 A** | 堵转。运动时 250~900 mA |
| **5V 轨合计** | ~165 mA | **~1.0 A** | |

**结论：boost 按 5V / 1.5A 输出设计**（1A 峰值留 50% 余量）。

> 舵机换 MG996R 这类大扭力（堵转 2.5A）要重算，而且会连带撞上 §4.1
> 保护板的过流点。**先确认舵机型号。**

电池侧要出的电流：`5V × 1.5A ÷ (3.7V × 0.9) ≈ 2.3A`。
**电池和保护板都得能出 2.3A**，这条在 §4.1 会再提一次。

## 3. 电源架构

### 3.1 电源树

```
                    ┌──────────────────────────────┐
   USB-C ──────────►│  XIAO ESP32C6                │
   (只用来充电、     │   ├ SGM40567 充电 → BAT 焊盘 │
    调程序)         │   ├ VBUS / BAT 自动切换       │
                    │   └ LDO → 3V3 脚             │
                    └───────▲──────────────┬───────┘
                            │              │
                     [TP1/TP2 顶针]        │ 3V3
                            │              ▼
   J1 JST ──┬───────────────┘          J3 屏幕/按键 8P
   电池座    │
            ├──[F1 自恢复保险丝 2A（选装）]
            │
            ├──[R1 100k]──┬──[R2 100k]── GND
            │             │
            │             └──► XIAO D2 / GPIO2（ADC）
            │
            └──[U1 Boost  TPS61088  3.0~4.2V→5.0V @1.5A]──► VM_5V
                                                                │
                                                          J2 舵机座
                                                          （+470µF 电解）
```

### 3.2 为什么这么简单

**「USB 在就用 USB、拔了就用电池」这件最难做对的事，XIAO 内部已经做好了。**
它的 PMIC 自己管 VBUS 和 BAT 的切换，不需要 MCU 参与，所以是真无缝。
我们只要把电池接到它的 BAT 焊盘上，那个能力就白送了。

上一版是我们自己用两个理想二极管重做一遍这套逻辑（旧 §3.3/§3.4）。
现在不做了——**这正是选方案甲的核心理由**：把风险交给已经验证过的电路。

### 3.3 电池节点（`VBAT`）上挂了什么

```
VBAT ──┬── J1.1（电池正极）
       ├── TP1（顶针 → XIAO BAT+）  ← 充电从这里进来
       ├── U1.VIN（boost 输入）      ← 舵机的电从这里出去
       └── R1（分压）
```

**这是一个真正的「电池节点」**——充电电流和放电电流都从这里过。
旧版刻意把负载从电池节点上挪开（为了躲「边充边放」，旧 §3.2），
**这一版挪不开了**：电池、充电器、负载三者必须在同一点上，因为我们用的
就是 XIAO 的充电器，而它只认 BAT 焊盘。

所以旧版担心的那个问题在这里**确实存在**，见 §4.3。

## 4. 电池与充电

### 4.1 ⚠️ 保护板不是可选项

**XIAO ESP32C6 没有过放保护。** 板载充电 IC 是 **SGM40567-4.2**，它只管充
（4.2V 截止，约 350mA），**不管放**。

- **带保护板的电池**（软包引线上多一块小 PCB，或 18650 自带保护头）→ 直接接
- **裸电芯** → 必须自己加保护板。不加的后果是过放到 2.5V 以下，电芯内部
  析锂、鼓包，**再充电时可能起火**

**先确认你手上的电池带不带保护板**，这是一条硬门槛，不是建议。

**还要确认保护板的过流点。** 1S 小容量软包的保护板常见过流点是 1.5~3A。
按 §2 的预算，舵机堵转时电池侧要到 2.3A——**如果保护板定在 1.5A，
现象会是「舵机一动整板就断电」**，看起来像固件死机，实际是保护板跳了。

> 选电池时问清楚过流保护点，要 **≥3A**。或者选小一号的舵机。

### 4.2 ⚠️ JST 座的极性必须拿万用表量

**锂电池接反会起火，这不是修辞。** 而 JST-PH 2.0 这个座子市面上**两种极性
都有**（官方 XIAO 扩展板的座子就被用户报告过极性是反的），电池引线的颜色
也不统一。

**做法**：装之前用万用表蜂鸣档，确认 JST 座哪一个脚通到 `VBAT`、哪一个通到
`GND`，再对比电池引线的红黑。**两个都对上了才插。**

**不要用「串一个二极管防反接」代替这一步。** 电池路径上串二极管会有两个后果：

- 充电器检测的是它自己那一侧的电压，二极管的压降会让它的充满判断点偏移，
  电池充不满或截止电压不对
- 放电时白白损失 0.3V，本来就紧的 3.0V 下限更早到

**靠防呆连接器 + 装前核对极性**，不靠二极管。

### 4.3 板上为什么没有充电 IC，代价是什么

XIAO 的充电器只认 BAT 焊盘，所以电池、充电器、负载挤在同一个节点上
（§3.3）。这就是经典的「**边充边放**」，代价是具体的：

- 充电器靠检测电池电压判断何时进 CV、何时截止。负载（boost）一直在抽电，
  **充电电流会被分走一部分**
- 结果：**插着 USB 时充电变慢**，尤其舵机频繁动作时
- XIAO 的充电电流本来就只有约 350mA，扣掉 boost 的输入电流后剩得更少

**这个代价是可接受的**，因为：

1. 本设备插着 USB 时通常在台面上调试，不是在跑舵机
2. 350mA 本来就要充很久，慢一点不改变使用方式
3. 换来的是省掉一整颗充电 IC + 保护电路 + 电源路径管理

> **想改的话**：换带电源路径的充电 IC（BQ24074 之类）能根治，但那就要回到
> **旧版**那套「负载不挂电池节点」的结构（旧 §3.2 加 §3.5），复杂度整个反弹
> 回上一版。第一版不做。
>
> ⚠️ 注意这里说的是**旧版**的 §3.x。本文件新的 §3.3 讲的是相反的事
> ——「一切都挂在电池节点上」。两处编号长得像，别串了。

### 4.4 保险丝（选装）

保护板已经管了过流和短路，所以 F1 是**冗余**的。要加就加 **2A 自恢复保险丝**，
注意两点：PTC 有几十到几百 mΩ 的常态电阻（会拉低电池电压），
而且**跳闸电流随温度降额**——夏天在密闭盒子里，2A 的 PTC 可能 1.2A 就跳。

**不加也说得过去**（保护板在）。加的话选 2A 以上，且别和舵机堵转撞车。

## 5. 电池电压检测（分压）

### 5.1 为什么是分压，不是电量计

**XIAO ESP32C6 的 ADC 只有 GPIO0~GPIO6 七个通道**（`soc/adc_channel.h` 里
只有 `ADC1_GPIO0_CHANNEL` … `ADC1_GPIO6_CHANNEL`，没有 ADC2）。这七个里：

| GPIO | 现状 |
|---|---|
| 0 / 1 | K1 / K2 |
| 2 | **本方案让给分压** |
| 3 | 模块内部天线开关，`variant.cpp` 开机就拉低 —— **不可挪用** |
| 4 / 5 / 6 | **没引到 XIAO 排针上** |

所以想上 ADC，**只能把某个按键挪走**。本方案把 **K3 从 D2 挪到 D6**
（D6 = GPIO16 是纯数字脚，按键不需要 ADC），GPIO2 空出来给分压。

K4 留在 D3/GPIO21，是因为 GPIO0 在 C6 上兼作 `XTAL_32K_P`，能不动就不动。

> 另一条路是挂 I2C 电量计（MAX17048 @ 0x36，不和屏幕的 0x3C 冲突），
> 不用占 ADC 也不用挪按键。**用户选了分压**，因为便宜且不用写驱动。
> 代价见 §5.4。

### 5.2 分压参数

| 项 | 值 | 理由 |
|---|---|---|
| R1 / R2 | **100kΩ / 100kΩ** | 1:2 分压 |
| C1 | **100nF**，紧贴 XIAO 的 D2 脚 | 采样时提供低阻电荷源 |
| 分压后 | 1.50 ~ 2.10 V | 3.0~4.2V 的一半 |
| 静态电流 | 4.2V / 200kΩ = **21 µA** | 可忽略 |

**为什么是 1:2 而不是更"省量程"的比值**：ESP32-C6 的 ADC 在最大衰减档
量程约 0~2.9V，2.1V 留了 0.8V 余量。想榨分辨率可以把比值调到 0.65
（→ 1.95~2.73V），但余量只剩 0.17V，**不划算**——12 位 ADC 在 1:2 下仍有
约 850 个码，分辨率过剩。

**为什么要有 C1**：R1∥R2 = 50kΩ 是相当高的源阻抗。ADC 采样瞬间要在一小段
时间内给内部采样电容充上电，50k 灌不够快，读出来会偏低。**100nF 紧贴引脚
就是干这个的**——它是个就近的电荷仓库。

### 5.3 固件侧要注意的

- **衰减档要选最大那档**（覆盖 2.1V）。档位不够的话读数会顶在满量程不动
- **第一次读数丢弃**，再连读多次取平均。C1 通过 50kΩ 充电的时间常数是
  5ms，两次读数挨太近会一次比一次低
- 用 `analogReadMilliVolts()` 取校准后的 mV，再 `× 2` 还原电池电压
  （它走 eFuse 里的出厂校准，比拿原始码自己去套线性公式准）

> 读数偏低或跳得厉害时，先把 R1/R2 降到 47kΩ（源阻抗 23.5k，时间常数
> 减半），不要急着改固件的平均次数。

### 5.4 分压法的两个固有缺陷（知道就好，不用修）

1. **插着 USB 时读到的是充电电压，不是电池电压。** CV 阶段会一直显示
   ~4.2V（≈满电），哪怕电池是空的。电量计芯片能区分，分压不能。
2. **锂电池的电压-SOC 曲线中段很平。** 3.7~3.9V 覆盖了大概一半容量，
   线性映射会让电量在 50% 附近赖着不动，然后在最后 20% 掉得飞快。
   固件里建议用一张分段表（3.0/3.5/3.7/3.8/3.9/4.0/4.2 → 0/10/30/50/70/85/100）
   而不是 `(v-3.0)/1.2*100`。

## 6. 舵机 5V（boost）

### 6.1 为什么非升压不可

**电池供电时，XIAO 的 5V 脚上什么都没有。** 那个脚在插 USB 时是 VBUS，
拔了 USB 就是空的（不是 0V 输出，是根本没有输出能力）。
而舵机要 4.8~6V。

所以舵机的 5V **只能自己从电池升上来**。这也是全板唯一的开关电源。

### 6.2 参数

| 项 | 值 |
|---|---|
| 输入 | `VBAT`，3.0~4.2V |
| 输出 | **5.00V** @ 1.5A（`VM_5V`） |
| 推荐芯片 | **TPS61088**（2.7~12V 输入，10A 开关） |
| 备选 | MT3608（便宜，但纹波差、无 EN、保护弱，只适合验证功能） |

**反馈电阻**：`Vout = Vref × (1 + R1/R2)`，Vref **以数据手册为准**
（我记的是 1.204V，**打样前自己核**）。要 5.00V 就是 `R1/R2 ≈ 3.15`。

### 6.3 EN 脚：接哪

两种接法，**先想清楚再画**：

- **接 VIN（常开）**——最简单，没有额外失效模式。**第一版建议这个。**
- **接一个空闲 GPIO**（D7/GPIO17、D9/GPIO20、D10/GPIO18 现在都空着）——
  锁不动的时候关掉 boost，省掉舵机的静态电流和可能的抖动

> ⚠️ **选 GPIO 控制之前，先确认机械结构。** 舵机断电就**松掉**，没有任何保持
> 力矩。如果拨片/锁舌是摩擦保持或靠倒角自锁，断电没问题；如果它靠舵机
> 硬顶着才保持在锁定位，**关 boost 等于自己开锁**——那就只能常开。
>
> 这一条要拿实物验证，别在图上想当然。

### 6.4 外围与布局

- 输入电容、电感、输出电容**紧贴 U1**，走线短而粗
- **开关节点（SW）铜面积要小**，它是主要辐射源
- FB 走线远离电感和 SW 节点
- 电感下方不要走敏感信号（尤其别走 I2C 和分压那两根）

## 7. ★ 机械：顶针（本方案唯一的新风险）

### 7.1 为什么需要它

**XIAO 的 `BAT+` / `BAT-` 不在那 2×7 排针上。** 排针 14 个脚是
11 个 D 脚 + `5V` + `GND` + `3V3`，**没有 BAT**。那两个焊盘在板子**背面**。

官方 XIAO 扩展板是怎么解决的：**两根朝上的弹簧顶针**，XIAO 插进母座时
正好压住背面那两个焊盘。本方案照抄这个做法。

### 7.2 尺寸

**母座高度已实测：8.5mm**（用户 2026-09-23 量的）。

| 项 | 说明 |
|---|---|
| XIAO 座 | 2× 7P 2.54mm **母座**，高 8.5mm |
| 顶针总高 | **8.5mm + 压缩量**，即选 9.5~10mm 的 |
| 压缩行程 | 1~1.5mm |
| 顶针型号 | P75 系列（P75-B1 / P75-LM2 之类），高度按上面挑 |

> 高度 = **母座高度 + 压缩量**，不是「等于母座高度」。顶针要有 1~1.5mm 的
> 预压量才压得住：压不实会时通时断（表现为随机重启），压太死会顶坏 XIAO
> 背面的焊盘。

### 7.3 板上的接收焊盘怎么画

**中心距已实测：2.5mm**（用户 2026-09-23 量的）。
**这个数很紧，它决定了焊盘能怎么画。**

**接收焊盘：**

- **沿两个焊盘的连线方向，不能拉长。** 2.5mm 中心距下，两个 3.5mm 的长圆
  会重叠掉 1mm。这个方向最多做到 **2.2mm**（留 0.3mm 间隙）
- **要拉长吃公差，就沿垂直于连线的方向拉**（比如 2.2 × 3.5mm 的竖椭圆）。
  捕获面积翻倍，两个焊盘又不会碰在一起
- 丝印画出 **XIAO 的外框轮廓**，装配时肉眼对位

**顶针要选细的：**

- **筒径挑 1.0mm 左右的，不要 1.5mm 的。** 2.5mm 中心距下，1.5mm 筒径只剩
  1.0mm 间隙，手焊很容易连锡
- P75 系列里挑细的那一档 —— **打样前拿卡尺量一下实物直径，别照型号名猜**

> ⚠️ **这 2.5mm 是整块板上最危险的一对相邻焊盘。**
> `BAT+` 和 `BAT−` 只隔 2.5mm，**一旦连锡就是锂电池直接短路**——
> 有保护板会跳（好事），没保护板就是起火。
>
> **焊完立刻量一次 `TP1 → TP2` 的电阻，应该是 ~200kΩ**（就是 R1+R2 那两颗
> 分压电阻串联的值）。**读 0Ω 就是连锡了**，趁没接电池赶紧返修。
> 这个检查五秒钟，是这一版最该养成习惯的一步。

### 7.4 极性：已确认

**背面朝上、Type-C 口朝上时：左侧焊盘 = `BAT−`，右侧焊盘 = `BAT+`。**
（用户 2026-09-23 读的板上丝印。）

**这个结论有两个独立来源对上了**，不是单点：

- **板上丝印**（用户直接读的）
- **官方 wiki**：「负极靠 `D8` 那侧，正极靠 `D5` 那侧」。而 XIAO ESP32C6
  正面（USB 朝上）左边是 D0~D6、右边是 5V/GND/3V3/D10/D9/D8/D7，
  所以 **D5 在左、D8 在右**；**翻到背面左右镜像** → D8 落在左边 = 负极在左。
  和丝印一致。

> ⚠️ **参考系是「背面朝上」。** 板子翻过来时左右是镜像的，只说「左边是负极」
> 而不说清楚看的是哪一面，就会接反。**我们板上画丝印时必须把参考系一起印
> 上去**（画一个 Type-C 口的方向示意 + `+`/`−`），否则装配时无从判断。

**装好后有一分钟就能做完的验证，而且不用接电池：**

1. 插上 USB，**先别接电池** —— XIAO 的充电器会在 BAT+ 上给出约 4.2V
2. 量我们板上 **TP1 → TP2** 的电压

| 读数 | 含义 |
|---|---|
| **+4.2V 左右** | 极性和接触都对 ✅ |
| **0V** | 顶针没压上（接触不良） |
| **负值** | 两根顶针**接反了**，立刻停下来改 |

这条同时验了「极性对不对」和「顶针压没压上」，是这一版最划算的一个测试。

### 7.5 万一压不上：板上留备用焊盘

在顶针旁边**留两个测试点焊盘**（接 `VBAT` 和 `GND`）。如果做出来发现顶针
接触不可靠，可以从 XIAO 背面直接焊两根细飞线到这两个焊盘上。

这违背「无需改线」的初衷，但**它是个只花两平方毫米的保险**，比重新打一版
板便宜得多。

## 8. 接口

### 8.1 屏幕 / 按键（J3，8P）

**线序已实测**：**看模块正面（显示面朝自己）**，从左到右是
`GND, 3V3, SCL, SDA, K4, K3, K2, K1`（用户 2026-09-23 提供）。

| J3 脚 | 信号 | 接到 XIAO | 说明 |
|---|---|---|---|
| 1 | **GND** | GND | **1 脚，丝印上要打明显标记** |
| 2 | **3V3** | U2.3V3 | **绝对不能是 5V**，屏幕是 3.3V 的 |
| 3 | SCL | D5 / GPIO23 | |
| 4 | SDA | D4 / GPIO22 | |
| 5 | K4 | D3 / GPIO21 | |
| 6 | K3 | **D6 / GPIO16** | **改过**，原来在 D2 |
| 7 | K2 | D1 / GPIO1 | |
| 8 | K1 | D0 / GPIO0 | |

> ⚠️ **按键是倒序的**（`K4 K3 K2 K1`），不是 `K1 K2 K3 K4`。
> 这个模块的按键排布是 K1 在最右边。照直觉画成 K1 打头就全错了。

> ⚠️ **参考系是「模块正面（显示面）朝向自己」。** 模块或板子一旦翻面，
> 左右就是镜像的。我们板上画 J3 封装时，**必须把「模块正面朝哪」和
> 「我们板面朝哪」对齐一遍**再定哪个焊盘是 1 脚——这一步没有捷径，
> 要在装配图上画出来看。
>
> **而且这种排针没有防呆**，插反了就是 `3V3` 和 `GND` 对调，一上电就烧。
> 所以丝印上给 J3 的 1 脚做明显标记（方焊盘 / 三角 / 圆点），写清
> 「1 脚 = GND」。
>
> **装配时再花 30 秒复核**：蜂鸣档确认**模块的 GND（屏幕排针的 GND，或
> I2C 座的金属壳）通到 J3 的 1 脚**。GND 是这 8 根线里唯一能靠电学认出来
> 的——**这一步能把前面所有的方向推理错误都兜住**，包括我给错的。

### 8.2 舵机（J2，3P）

| 信号 | 接到 | 说明 |
|---|---|---|
| 红（VCC） | `VM_5V` | 来自 boost |
| 棕（GND） | GND | 走粗线回星形接地点 |
| 橙（信号） | D8 / GPIO19 | |

**舵机座旁边要有 470µF 电解 + 100nF。** 舵机是感性负载，启动和换向时电流
突变靠陶瓷电容顶不住。**紧贴 J2**，不是紧贴别的。

### 8.3 XIAO 座（U2）

2× 7P 2.54mm 母座。**引脚顺序照立创库里的现成 XIAO 符号**，
别自己按 GPIO 顺序摆——那个顺序不是 GPIO 顺序。

**XIAO 的 `5V` 脚在本方案里是空脚**（不接任何东西，见 §0 和 §3.2）。

## 9. 会翻车的地方

### 9.1 舵机地电流不能穿过逻辑地

舵机电流（安培级）如果从 ESP32 的地线上回流，地电位会被抬起几百 mV，
表现为**随机复位、屏幕闪烁、按键误触发**。

**做法**：星形接地。舵机座的 GND 单独走粗线回到**电池座 J1 的 GND 脚**，
不要串到逻辑区的地上。逻辑地单独一路回到同一点。两层板用铺铜 + 开槽引导；
四层板有专门地平面会好很多。

### 9.2 XIAO 的天线净空区

XIAO 的 PCB 天线在板子一端，**天线正下方和周围不能有铜**，否则 WiFi/蓝牙
距离会明显变差。XIAO 插上我们的板子后，天线那一端必须**悬空在板边之外**，
或者在 PCB 上挖一个对应的缺口。

**这条必须画进板框。** 忘了的话板子做出来无线基本废掉。

### 9.3 没装电池时舵机不动

电池节点没有电压 → boost 不工作 → 舵机没电。**XIAO 自己照常跑**（吃 USB），
屏幕、按键、UI 全都正常，**只有舵机不响应**。

这不是 bug，是「舵机只从电池升压取电」（方案 A）的直接结果。调试时别把它
当成舵机坏了。

> 想连 USB 就能试舵机，可以在 `XIAO_5V` 和 `U1.VIN` 之间**留一个肖特基
> 二极管 + 一个焊接跳线**，默认不焊。焊上之后插 USB 时 boost 改吃 USB 的电
> （4.7V > 电池最高 4.2V，二极管的单向性保证拔了 USB 不会倒灌），
> 代价是舵机电流会从电脑 USB 口出。**选装，第一版建议不焊。**

### 9.4 别把 XIAO 的 5V 脚接到任何地方

本方案里 `5V` 脚悬空。**不要**因为「顺手」把它接到 `VM_5V`——那会把 USB
的 VBUS 和我们的 boost 输出短在一起，插上 USB 时两边对灌。
旧版为了这个专门加了防倒灌二极管（旧 §6.2），**现在不接就没有这个问题**。

## 10. 摄像头（已排除，存档备查）

ESP32-C6 **没有** DVP/LCD_CAM 并口，官方 `esp_cam_sensor` 支持表里 C6 那行
MIPI-CSI 和 LCD_CAM DVP 都是 **N/A**，只有 SPI。而市面上便宜的摄像头模块
（OV2640/OV3660）全是并口的，经典 `esp_camera` 库也不支持 SPI 摄像头。

**结论**：以后要加摄像头，只能换成 **ESP32-S3**（有 LCD_CAM，是摄像头项目的
标准选择），而且换主控意味着换插座、改引脚、重写驱动。
**这是一次主控换代，不是加个外设。**

## 11. 已确认 / 还没定

### 11.1 已确认（2026-09-23 实测）

| 事项 | 结论 | 记在哪 |
|---|---|---|
| 母座高度 | **8.5mm** | §7.2 |
| BAT 焊盘极性 | 背面朝上、Type-C 朝上时 **左− 右+** | §7.4 |
| 连接器线序 | **模块正面朝自己**，左→右 `GND, 3V3, SCL, SDA, K4, K3, K2, K1` | §8.1 |
| **BAT 焊盘间距** | **2.5mm**（中心距） | §7.3 |

### 11.2 还没定

打样前必须确认，**每一条都会导致废板或返工**：

| # | 事项 | 怎么定 | 影响 |
|---|---|---|---|
| 1 | **舵机具体型号** | 查铭牌/买之前问 | 决定 boost 电流；MG996R 级要重算整个 §2 |
| 2 | **电池规格** | 容量、尺寸、**保护板过流点** | 决定板子尺寸；过流点 <3A 会和舵机撞车（§4.1） |
| 3 | **电池带不带保护板** | 看引线上有没有小 PCB | 裸电芯必须加，这是安全项（§4.1） |
| 4 | **顶针的筒径** | 卡尺量实物 | 2.5mm 中心距下只能选细的（§7.3） |
| 5 | 板子尺寸和层数 | 建议**四层**（完整地平面，对舵机噪声帮助很大） | 两层能省一半钱但难做 |
| 6 | 贴片还是手焊 | 手焊建议全用 0805 以上 + SOP，避开 QFN | TPS61088 是 QFN，手焊有难度 |
| 7 | 打样厂家 | 嘉立创 / 捷配，确认元件在**基础库**里 | 不在基础库要加钱或自己焊 |

## 12. 建议的推进顺序

1. **先定 §11.2 的 1、2、3**（舵机型号、电池规格、有没有保护板）——
   这三项决定选型和尺寸，其它都排在后面
2. **第一版只打电源部分**：J1 电池座 + 顶针 + boost + 分压 + 舵机座，
   **不加屏幕座和按键**
   - 这块板插上 XIAO 和电池就能验证：充电通不通、顶针接触可不可靠、
     boost 带不带动舵机、ADC 读数准不准
   - **顶针是这一版唯一没先例可抄的地方**（官方扩展板有，但尺寸不同），
     单独花一版验证它，比打完整个板子发现压不上强太多
3. 电源和顶针都验证过了，再把 XIAO 座、屏幕座、按键加上打第二版
