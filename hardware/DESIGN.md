# PCB 版设计方案

把 `espc6-lock` 从「XIAO 开发板 + 杜邦线」做成一块 PCB。

**本方案要解决的唯一真正难点是电源。** ESP32 和屏幕那部分现有连接照搬即可，
12V 输入、锂电池、两个电机凑在一起才是会翻车的地方——尤其是
「边充边放」和「电机把 MCU 拉复位」这两个经典坑。

> ⚠️ **本文全部是纸面设计，没有一个元件在实机上验证过。**
> 所有数值（电流、电容、线宽）都是按数据手册和常见做法估的。
> 打样前请自行复核，尤其是 §3 的电源部分。

## 1. 需求

| 项 | 决定 | 来源 |
|---|---|---|
| DC 输入 | 12V | 用户选定 |
| 电池 | 1S 锂电池（3.0~4.2V），**备用** | 用户选定 |
| 供电架构 | DC 为主，电池备份，**无缝切换（UPS 式）** | 用户选定 |
| 主控 | 保留 XIAO ESP32C6，**做插座**插上去 | 用户选定 |
| 舵机 | 保留，驱动锁舌 | 现有设计 |
| 步进电机 | **只预留接口和驱动座，用途待定** | 用户选定 |
| 摄像头 | **不做**。ESP32-C6 无并口摄像头接口，只有 SPI | 见 §7 |

## 2. 负载电流预算

这是选电源芯片的依据，先算清楚：

| 负载 | 典型 | 峰值 | 说明 |
|---|---|---|---|
| XIAO ESP32C6 | 80 mA | 350 mA | WiFi 发射瞬间 |
| OLED | 15 mA | 20 mA | |
| 舵机（SG90/MG90S 级） | 150 mA | **1.0 A** | 堵转。运动时 250~900 mA |
| 步进（预留，NEMA17 + A4988） | — | **1.5 A** | 由驱动限流决定，不是电机铭牌 |
| **合计** | ~250 mA | **~2.9 A** | |

**结论：5V 轨按 3A 设计。** 步进现在不装，但接口和走线按装了的规格留，
否则以后想加就得重新打板。

> 如果舵机换 MG996R 这类大扭力（堵转 2.5A），5V 轨要按 4A 以上重算，
> 整个电源方案得改。**先确认舵机型号。**

## 3. 电源架构

### 3.1 电源树

```
DC 12V 输入
  │
 [F1 自恢复保险丝 2A]
  │
 [Q1 P-MOS 防反接]──[D1 TVS SMBJ16A]
  │
  ├──────────────────────────────────► VM_12V ──► 步进驱动 VM（预留）
  │
  ├──[Buck1  MP2315  12V→5V @3A]──► 5V_DC
  │                                    │
  │                                    ├──[充电 IC  TP4056+DW01A]──► 1S LiPo
  │                                    │                                 │
  │                                    │        [Boost  TPS61088] ◄──────┘
  │                                    │        3.7V→5V @3A
  │                                    │              │
  │                                    │         [D4 理想二极管]
  │                                    │              │
  └────────────────────────────────────┴──[D2 理想二极管]──┴──► VM_5V
                                                                    │
                                                    ┌───────────────┼───────────────┐
                                                    │               │               │
                                                  舵机          步进 VDD      [D3]─► XIAO 5V
                                                                                      │
                                                                              XIAO 板载 LDO
                                                                                      │
                                                                                  3V3 ──► OLED
```

### 3.2 为什么是这个结构

**两套转换器分别走各自最高效的模式。** 12V 下来用 buck 降压，
电池上来用 boost 升压，两边都工作在擅长区。用一个 buck-boost 也能做（见 §3.5），
但 buck-boost 芯片贵、外围复杂，对第一版不划算。

**DC 和电池在 5V 这一层做 ORing。** 谁电压高谁供，二极管是即时导通的，
**不需要 MCU 参与，所以是真无缝**——断 DC 的瞬间电池就接管了。

**电池只在自己那一路放电，负载不挂在电池节点上。** 这一点很关键：
TP4056 那类充电 IC 最出名的问题是「边充边放」——负载直接挂在电池上，
充电器靠检测电池电压判断充满，负载一大就永远判不满，而且电池电压被拉低
可能触发保护板断电。**本方案里负载接在 VM_5V（来自 Buck1），不接电池**，
所以这个问题从结构上就不存在，充电时也能正常带负载。

### 3.3 关键细节：两个 5V 源会「抢」

D2 和 D4 让 DC 和 boost 都能供 VM_5V。如果两个都开着且都输出 5.00V，
它们会分摊电流，谁都不在正常工作点。**必须让它们分开工作：**

- **方案（推荐）**：Buck1 输出调到 **5.15V**，boost 调到 **5.00V**。
  理想二极管自动选高的。DC 在时 Buck1 独占；DC 一断，boost 立刻接管
  （它一直开着，没有启动延迟）。
  代价：DC 在时 boost 空载运行，耗电池约 1~2 mA，可忽略。
- **方案（更省电）**：用 12V 存在检测关掉 boost 的 EN。
  但 boost 软启动要 ~1ms，切换瞬间 VM_5V 会掉，靠大电容顶住。
  要保证 VM_5V 上至少有 **470µF** 才有足够保持时间。

推荐前者：多耗 1mA 换掉一个「切换瞬间可能复位」的风险，值。

### 3.4 理想二极管不能省成肖特基

肖特基（SS34 之类）压降 0.4~0.6V，3A 时：

- VM_5V 只剩 **4.4~4.6V**，低于舵机 4.8V 的额定下限，扭力下降
- 发热 **1.5W**，SS34 的 SMB 封装扛不住，会烫

用 **P-MOSFET 理想二极管**（LTC4412 控制器，或分立 P-MOS + 比较器）。
压降 = I × Rds(on)，选 20mΩ 的管子在 3A 下只有 60mV。

> 只是验证功能的第一版，肖特基可以接受——但要清楚舵机会变弱。

### 3.5 备选：单 buck-boost（更优雅但更贵）

```
DC 12V ─[Buck 12→5V]─► 5V_CHG ─[充电IC带电源路径 BQ24074]─► VSYS(3.0~5.0V)
                                          │                       │
                                      1S LiPo              [Buck-Boost 5V @3A]
                                                                  │
                                                               VM_5V
```

**优点**：单一转换器始终掌控输出，切换真正无扰动，没有 ORing 抢电流的问题。
**缺点**：3A 的 buck-boost 芯片（LTC3119 之类）单价 ~¥70 起，外围也复杂。

**什么时候选它**：如果实机发现无缝切换做不好、或者舵机在切换瞬间抖动。

## 4. 选型

> **所有型号都需要你自己核对立创/嘉立创的现货和封装。** 我无法查库存。

### 4.1 电源

| 位号 | 作用 | 推荐型号 | 备注 |
|---|---|---|---|
| F1 | 过流保护 | 自恢复保险丝 2A / 16V | 或一次性保险丝座 |
| Q1 | 防反接 | AO3401A（P-MOS） | 或专用理想二极管 |
| D1 | 浪涌 | SMBJ16A（TVS） | 12V 输入必加 |
| Buck1 | 12V→5V @3A | **MP2315** | 4.5~24V 输入，同步整流。备选 MP2338 |
| Boost | 3.7V→5V @3A | **TPS61088** | 2.7~12V 输入，10A 开关，余量大 |
| 充电 | 1S 充电 | **TP4056 + DW01A + FS8205A** | 线性，1A。**必须配散热铺铜** |
| D2/D4 | ORing | P-MOS 理想二极管 | 见 §3.4 |
| D3 | XIAO 隔离 | SS14 | 防止 USB 倒灌整板，见 §6.2 |

**TP4056 的散热问题**：线性充电，(5V − 3.7V) × 1A ≈ **1.3W** 全变热。
SOP-8 封装靠引脚散热，**必须把底部和周围铺大面积铜**，否则会热到降流甚至保护。
想省心就用开关充电 IC（BQ25601 等），但要 I2C 配置，复杂一档。

充电电流由 `R_PROG` 决定：`I = 1200 / R`（kΩ→A）。要 1A 就 1.2kΩ，
要 500mA 就 2.4kΩ。**第一版建议 500mA**，发热小一半。

### 4.2 主控与接口

| 项 | 规格 |
|---|---|
| XIAO 座 | 2× 7P 2.54mm **母座**（XIAO 每边 7 脚） |
| OLED | 4P 2.54mm 排针（GND/VCC/SCL/SDA） |
| 舵机 | 3P 2.54mm 排针（棕-GND / 红-5V / 橙-信号） |
| 步进驱动座 | **16P 2×8 2.54mm 母座（StepStick 兼容）** |
| 步进电机 | 4P 螺钉端子（KF301-4P） |
| DC 输入 | DC-005 电源座（5.5/2.1mm） |

**步进驱动为什么用座而不是焊死**：A4988 / DRV8825 / TMC2209 都是
StepStick 16P 兼容尺寸。放个母座，想用哪个插哪个，不用焊 SMD，
以后想升级 TMC2209（静音）也直接换。**这正好对上「用途待定」。**

### 4.3 被动件

| 位置 | 值 | 原因 |
|---|---|---|
| VM_5V 总储能 | **470µF 电解 + 100nF** | 切换保持 + 高频去耦 |
| 舵机座旁 | 470µF 电解 + 100nF | 舵机是感性负载，启动电流突变 |
| 步进驱动座旁 | 100µF 电解 + 100nF | A4988 手册明确要求 |
| VM_12V | 220µF + 100nF | |
| Buck1 输入 | 22µF 陶瓷 + 100nF | 靠近 IC |
| 每个 IC 电源脚 | 100nF | 靠近引脚 |

**电机的电解电容不是可选项。** 电机换向产生的电流突变靠陶瓷电容顶不住，
必须有电解。位置**紧贴接线座**，不是紧贴 IC。

## 5. 步进电机预留部分

按「插上就能用」的标准留，而不是只留几个焊盘：

| 项 | 做法 |
|---|---|
| 驱动座 | 16P StepStick 母座 |
| VM | 接 **VM_12V**（12V）。A4988/DRV8825 要 8V 以上才有扭力 |
| VDD | 接 VM_5V（逻辑供电） |
| 电机 | 4P 螺钉端子 |
| 使能/方向/步进 | 接三个空闲 GPIO，**留 0Ω 跳线或排针可选** |
| 限位开关 | 留 2P 排针（步进多半需要归零） |

> ⚠️ **步进接 12V，意味着拔掉 DC 后步进就不工作了。**
> 因为电池只有 3.7V，而 A4988 最低 8V。这不是疏忽，是取舍：
> 给步进单独做一路 12V boost 会让电源复杂度翻倍。
> 如果以后确定步进必须在电池下工作，再加一路 boost 到 12V。

**A4988 的电流必须先用板上的电位器调好再插电机**，否则默认值可能烧电机。
这条写进丝印或说明书。

## 6. 会翻车的地方（重点）

### 6.1 电机地电流不能穿过逻辑地

电机电流（安培级）如果从 ESP32 的地线上回流，地电位会被抬起几百 mV，
表现为**随机复位、屏幕闪烁、按键误触发**。

**做法**：星形接地。每个电机接线座的 GND 单独走粗线回到
**输入大电容的负极**，不要串到逻辑区的地上。逻辑地单独一路回到同一点。
两层板用铺铜 + 开槽引导；四层板有专门地平面会好很多。

### 6.2 USB 插上时不要倒灌

XIAO 的 5V 脚和它自己的 USB VBUS 是连通的（**需对照 XIAO 原理图确认是否有二极管**）。

如果直接把 VM_5V 接到 XIAO 的 5V 脚，插上 USB 调程序时，
USB 的 5V 会**通过 XIAO 反灌进整个 VM_5V**——而 VM_5V 上挂着舵机和步进。
轻则电脑 USB 口限流，重则烧口。

**做法**：D3（SS14）串联在 VM_5V → XIAO 5V 之间，阳极朝 VM_5V。
这样 USB 电流出不去（二极管反向截止），而 VM_5V 能正常给 XIAO 供电。

> 3.3V 不用自己做——直接用 XIAO 的 3V3 脚给 OLED（约 20mA，毫无压力）。

### 6.3 XIAO 的天线净空区

XIAO 的 PCB 天线在板子一端，**天线正下方和周围不能有铜**，
否则 WiFi/蓝牙距离会明显变差。XIAO 插上我们的板子后，
天线那一端必须**悬空在板边之外**，或者在 PCB 上挖一个对应的缺口。

**这条必须画进板框。** 忘了的话板子做出来无线基本废掉。

### 6.4 开关电源的布局

- Buck1 的输入电容、电感、输出电容**紧贴 IC**，走线短而粗
- **开关节点（SW）铜面积要小**，它是主要辐射源
- 反馈（FB）走线远离电感和 SW 节点
- Buck 的电感下方**不要走敏感信号**

### 6.5 两个电机的线要能插得进

舵机和步进的接线座要**留出手指或螺丝刀的空间**，
不要被屏幕排针或 XIAO 挡住。这是实际装配时才发现的问题。

## 7. 摄像头（已排除，存档备查）

ESP32-C6 **没有** DVP/LCD_CAM 并口，官方 `esp_cam_sensor` 支持表里
C6 那行 MIPI-CSI 和 LCD_CAM DVP 都是 **N/A**，只有 SPI。而市面上便宜的
摄像头模块（OV2640/OV3660）全是并口的，经典 `esp_camera` 库也不支持 SPI 摄像头。

**结论**：以后要加摄像头，只能换成 **ESP32-S3**（有 LCD_CAM，是摄像头项目的标准选择），
而且换主控意味着换插座、改引脚、重写驱动。**这是一次主控换代，不是加个外设。**

## 8. 还没定的事

打样前需要确认：

| # | 事项 | 影响 |
|---|---|---|
| 1 | **舵机具体型号** | 决定 5V 轨电流（SG90 是 1A，MG996R 是 2.5A），可能要重算整个电源 |
| 2 | 电池规格 | 18650（带座）还是软包（带线）？容量？决定板子尺寸和充电电流 |
| 3 | 板子尺寸和层数 | 建议**四层**（有完整地平面，对电机噪声帮助很大）。两层能省一半钱但难做 |
| 4 | 贴片还是手焊 | 手焊建议全用 0805 以上 + SOP 封装，避开 QFN |
| 5 | 按键放哪 | 继续用 OLED 模块自带的 K1~K4，还是在 PCB 上做独立按键 |
| 6 | 打样厂家 | 嘉立创 / 捷配。注意确认元件在**基础库**里，否则要加钱或自己焊 |

## 9. 建议的推进顺序

1. **先确认 §8 的 1、2 两项**（舵机型号、电池规格）——这两项直接影响电源选型
2. 按本方案画原理图，重点复核 §3 电源部分
3. 先打**只有电源部分**的板（12V 输入 + buck + 充电 + boost + ORing），
   验证切换和带载。**不要一次打全板**
4. 电源验证通过后，再把 XIAO 座、屏幕、电机座加上去打第二版

第 3 步很重要。电源是这个项目唯一有真实失败风险的部分，
把它单独验证一遍，比打完整个板子发现切换有问题要省太多时间和钱。
