# 网络表

配合 `DESIGN.md` 使用。这份表用来在嘉立创EDA Pro 里录入连接。

## 怎么用这份表

**不要照着拉线。** 在嘉立创EDA 里更快的做法是：

1. 从立创库放好元件
2. 给每个引脚**贴网络标签**（放置 → 网络标签），标签名照抄本表的「网络名」
3. 同名标签自动连成一个网络，不用画长线
4. 最后用「设计 → 检查」看有没有漏连

这样画出来的图可读性也更好——电源和地靠标签，只有局部才拉线。

> **引脚号以立创库里的符号为准。** 本表给的是**引脚功能名**
> （VIN / SW / FB / BAT 这种），不是引脚序号。
> 我手上没有这些芯片的数据手册，凭记忆写序号很可能错，而那比不写更糟。
> 符号里的引脚名和本表一致，对照着贴就行。

> **本表各节里的 `GND` 行是同一个网络**，分节写只是为了就着各自的功能看。
> 贴标签时它们全都叫 `GND`。星形接地的走法见 §7。

### 物理排布（画 XIAO 座封装时用）

**正面朝上、USB-C 口朝上**时（来源：NuttX 的 XIAO ESP32C6 板级文档，
「从 USB 口起逆时针编号」）：

```
            ┌── USB-C ──┐
     D0 ────┤           ├──── 5V
     D1 ────┤           ├──── GND
     D2 ────┤           ├──── 3V3
     D3 ────┤  XIAO C6  ├──── D10
     D4 ────┤           ├──── D9
     D5 ────┤           ├──── D8
     D6 ────┤           ├──── D7
            └───────────┘
```

**注意左右两列的脚数都是 7**，而且**右列上三个是电源脚**（5V / GND / 3V3），
不是从 D7 开始。

> **还是要在立创库里搜现成的 XIAO 符号对照一遍再画。** 上面这个排布是从
> 第三方板级文档推的，和 Seeed 自己的图应该一致，但**插座画错整板报废**，
> 值得多花五分钟。
>
> 这张图还有一个用处：**§3.3 的电池极性判断依赖它**（`D5` 在左、`D8` 在右）。

### 为什么 K3 和 D2 对调

ESP32-C6 的 ADC **只有 GPIO0~GPIO6 七个通道**（没有 ADC2），其中：

- GPIO0/1 被 K1/K2 占了
- GPIO3 被 `variant.cpp` 开机拉低当射频开关用（且不在排针上）
- GPIO4/5/6 没引到排针上

**想让分压上 ADC，只能从 GPIO0/1/2 里抢一个。** 按键不需要 ADC，
所以把占了 GPIO2 的 K3 挪到 D6（GPIO16，纯数字脚），GPIO2 让给分压。

> 为什么不动 GPIO0：它在 C6 上兼作 `XTAL_32K_P`，能不动就不动。

### ⚠️ `5V` 脚必须悬空

**不要**因为「顺手」把 XIAO 的 `5V` 脚接到 `VM_5V`。那个脚和 USB 的 VBUS
是连通的，接上去会让 USB 和 boost 输出对灌。

本方案里舵机的 5V 全部由 U1 从电池升上来，**不需要**碰这个脚。
（旧版方案曾用它，还为此加了一颗防倒灌二极管——现在不接，问题就不存在。）

## 2. 电池与充电

### 2.1 ⚠️ 这一节看 `DESIGN.md` §4.1，先确认电池带不带保护板

**XIAO ESP32C6 没有过放保护**——板载 SGM40567-4.2 只管充电，不管放电。
裸电芯直接接上去，过放会鼓包，**再充电可能起火**。

- **带保护板** → 按本表接
- **裸电芯** → 先自己加保护板（DW01A + FS8205A 的官方典型电路，
  或者市面上现成的「1S 保护板」小模块），串在电池和 J1 之间

**还要确认保护板的过流点 ≥3A**，否则舵机一堵转就整板断电（DESIGN.md §4.1）。

### 2.2 连接

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VBAT` | J1.1（正极）, F1.1 | 电池座出来先进保险丝 |
| `VBAT` | F1.2, TP1, R1.1, U1.VIN, C2.+ | 保险丝之后的电池节点 |
| `GND` | J1.2（负极）, TP2, R2.2, C1.2, C2.−, U1.GND, C3.−, R4.2, C4.−, C5.2, J2.棕 | 星形接地点在这条线上，见 §7 |
| `5V`(XIAO) | **不接** | 见 §1 的警告 |

**不装 F1 时**：`J1.1` 直接连到 `TP1 / R1.1 / U1.VIN / C2.+`，
也就是把 F1 短路掉。

### 2.3 ⚠️ JST 极性必须实测

**锂电池接反会起火。** JST-PH 2.0 这个座子市面上两种极性都有
（官方 XIAO 扩展板就被报告过极性是反的），电池引线的红黑也不统一。

**装之前用万用表蜂鸣档确认**：J1 哪个脚通 `VBAT`、哪个通 `GND`，
再和电池引线对上。**两个都对上了才插电。**

**不要在电池路径上串二极管防反接**——压降会让充电器的充满判断点偏移，
放电时还白损失 0.3V。见 DESIGN.md §4.2。

## 3. ★ 顶针（本方案唯一没有先例可抄的地方）

### 3.1 它解决什么问题

**XIAO 的 `BAT+` / `BAT-` 不在排针上**，在板子背面。
排针 14 个脚是 11 个 D 脚 + `5V` + `GND` + `3V3`，没有 BAT。

官方 XIAO 扩展板用**弹簧顶针**顶住背面焊盘，本方案照抄。

```
   XIAO 背面焊盘
   ─────●─────●─────      ← BAT− 和 BAT+
        ▲     ▲
        │     │             ← 顶针压缩 1~1.5mm
   ─────┴─────┴─────       ← 我们板上的长圆焊盘
```

### 3.2 连接

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VBAT` | TP1 | 顶到 XIAO 的 **BAT+** |
| `GND` | TP2 | 顶到 XIAO 的 **BAT−** |

### 3.3 ✅ 哪个焊盘是正极（已确认）

**背面朝上、Type-C 口朝上时：左侧 = `BAT−`，右侧 = `BAT+`**
（用户 2026-09-23 读的板上丝印）。

两个独立来源对上了：**板上丝印**，和**官方 wiki** 的「负极靠 `D8` 那侧、
正极靠 `D5` 那侧」——D5 在左、D8 在右（见 §1 的物理排布图），
翻到背面左右镜像 → D8 落到左边 = 负极在左。一致。

> ⚠️ **参考系是「背面朝上」。** 板子翻过来左右是镜像的，所以**我们板上画
> 丝印时必须把参考系一起印上去**（Type-C 口方向示意 + `+`/`−`），
> 否则装配时无从判断。

**装好后不用接电池就能验，一分钟：** 插上 USB，量我们板上 `TP1 → TP2`。

| 读数 | 含义 |
|---|---|
| **+4.2V 左右** | 极性和接触都对 ✅ |
| **0V** | 顶针没压上（接触不良） |
| **负值** | 两根顶针接反了，立刻停下来改 |

> XIAO 的充电器会在它的 BAT+ 上给出约 4.2V，所以**不接电池也有电压可量**——
> 这条同时验了「极性对不对」和「顶针压没压上」。

### 3.4 板上接收焊盘怎么画

**中心距已实测：2.5mm**（用户 2026-09-23 量的）——**这个数很紧，决定了形状**。

- **沿两个焊盘的连线方向不能拉长**（2.5mm 中心距下，两个 3.5mm 长圆会重叠
  1mm）。这个方向最多 **2.2mm**，留 0.3mm 间隙
- **要吃公差就沿垂直方向拉**（比如 2.2 × 3.5mm 的竖椭圆），捕获面积翻倍，
  两个焊盘又不会碰到一起
- **极性要能一眼看出来**：`BAT+` 焊盘旁丝印 `+`，并且**把参考系一起印上去**
  （Type-C 口的方向示意）——见 §3.3 的警告
- 丝印画出 **XIAO 的外框轮廓**，装配时肉眼对位
- **旁边留 TP3 / TP4 两个测试点焊盘**（分别接 `VBAT` 和 `GND`）。
  顶针万一接触不可靠，可以从 XIAO 背面焊两根细飞线过来。
  **这是只花两平方毫米的保险，别省。**

**顶针选细的**：筒径挑 **1.0mm 左右**，不要 1.5mm 的（2.5mm 中心距下只剩
1.0mm 间隙，手焊容易连锡）。P75 系列里挑细的那档，**拿卡尺量实物，别照
型号名猜**。

> ⚠️ **这 2.5mm 是整块板上最危险的一对相邻焊盘。** `BAT+` 和 `BAT−` 只隔
> 2.5mm，**连锡就是锂电池直接短路**——有保护板会跳（好事），没保护板起火。
>
> **焊完立刻量 `TP1 → TP2` 的电阻，应该是 ~200kΩ**（R1+R2 串联值）。
> **读 0Ω 就是连锡了**，趁没接电池赶紧返修。这个检查五秒钟，值得养成习惯。

### 3.5 高度

**母座高度已实测：8.5mm**（用户 2026-09-23 量的）。

顶针总高 = **8.5mm + 压缩量 1~1.5mm** → **选 9.5~10mm 的**（P75 系列有各种高度）。

> 是「母座高度 **加** 压缩量」，不是「等于母座高度」。要有预压量才压得住：
> 压不实会时通时断（表现为随机重启），压太死会顶坏 XIAO 背面的焊盘。

## 4. 电池分压

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VBAT` | R1.1 | 分压上端 |
| `ADC_VBAT` | R1.2, R2.1, C1.1, U2.D2 | 分压中点 → GPIO2 |
| `GND` | R2.2, C1.2 | |

- **R1 = R2 = 100kΩ 1%**，1:2 分压，3.0~4.2V → 1.50~2.10V
- **C1 = 100nF，紧贴 XIAO 的 D2 脚**。R1∥R2 = 50kΩ 是高源阻抗，
  采样瞬间灌不够电荷，读数会偏低；C1 是就近的电荷仓库
- 静态电流 21µA，可忽略

参数怎么定的、固件侧要注意什么，见 `DESIGN.md` §5。

## 5. 舵机升压

### 5.1 主回路

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VBAT` | U1.VIN, C2.+ | boost 输入（电池节点，和充电共用） |
| `GND` | U1.GND, C2.−, C3.−, R4.2, C4.−, C5.2 | |
| `SW1` | U1.SW, L1.1 | 开关节点，**铜面积要小** |
| `VM_5V` | L1.2, C3.+, R3.1 | boost 输出，**设定 5.00V** |
| `FB1` | U1.FB, R3.2, R4.1 | 反馈分压中点 |

**输出电压**：`Vout = Vref × (1 + R3/R4)`。Vref **以数据手册为准**
（我记的是 1.204V，**打样前自己核**）。要 5.00V 就是 `R3/R4 ≈ 3.15`。

**外围（电感、补偿、软启动）照 TPS61088 数据手册的典型应用电路接**，
本表只给网络名，不给具体值。

### 5.2 EN 脚

| 网络名 | 连接 | 说明 |
|---|---|---|
| （常开） | U1.EN → `VBAT` | **第一版建议这个**，最简单 |
| `BOOST_EN` | U1.EN → U2.D7（或 D9 / D10） | 可选：空闲时关掉舵机轨 |

> ⚠️ **走 GPIO 控制之前，先确认机械结构。** 舵机断电就**松掉**，
> 没有任何保持力矩。拨片若靠舵机硬顶着才保持在锁定位，**关 boost 等于自己开锁**。
> 拿实物验证，别在图上想当然。详见 `DESIGN.md` §6.3。

D7 / D9 / D10 现在都空着（见 §1）。

## 6. 显示与按键

**线序已实测**：**看模块正面（显示面朝自己）**，从左到右是
`GND, 3V3, SCL, SDA, K4, K3, K2, K1`（用户 2026-09-23 提供）。

| J3 脚 | 网络名 | 连接 | 说明 |
|---|---|---|---|
| **1** | `GND` | U2.GND | **1 脚，丝印上要打明显标记** |
| 2 | `3V3` | U2.3V3 | XIAO 的 LDO 输出。**绝对不能是 5V** |
| 3 | `I2C_SCL` | U2.D5 | |
| 4 | `I2C_SDA` | U2.D4 | |
| 5 | `KEY4` | U2.D3 | |
| 6 | `KEY3` | **U2.D6** | **改过**，原来在 D2 |
| 7 | `KEY2` | U2.D1 | |
| 8 | `KEY1` | U2.D0 | |

> ⚠️ **按键是倒序的**（`K4 K3 K2 K1`），不是 `K1 K2 K3 K4`。
> 这个模块的按键排布是 K1 在最右边。照直觉画成 K1 打头就全错了。

> ⚠️ **参考系是「模块正面（显示面）朝向自己」。** 模块或板子一旦翻面，
> 左右就是镜像的。画 J3 封装时要**把「模块正面朝哪」和「我们板面朝哪」
> 对齐一遍**再定哪个焊盘是 1 脚——这一步没有捷径，要在装配图上画出来看。
>
> **而且这种排针没有防呆**，插反了就是 `3V3` 和 `GND` 对调，一上电就烧。
> 所以丝印上给 J3 的 1 脚做明显标记（方焊盘 / 三角 / 圆点），写清
> 「1 脚 = GND」。
>
> **装配时再花 30 秒复核**：蜂鸣档确认 **模块的 GND（屏幕排针的 GND，
> 或 I2C 座的金属壳）通到 J3 的 1 脚**。GND 是这 8 根线里唯一能靠电学
> 认出来的——**这一步能把前面所有的方向推理错误都兜住**。

### ⚠️ `3V3` 不能换成 `5V`

屏幕是 3.3V 的（SSD1315 模块虽然有的标 5V 兼容，但本项目一直是 3.3V），
而且 `5V` 脚在本方案里是悬空的（§1）。

## 7. 舵机

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VM_5V` | J2.红, C4.+, C5.1 | 来自 boost |
| `GND` | J2.棕, C4.−, C5.2 | **走粗线回 J1 的 GND 脚** |
| `SERVO_PWM` | J2.橙, U2.D8 | |

**C4（470µF 电解）紧贴 J2**，不是紧贴别的。舵机是感性负载，
换向时电流突变靠陶瓷电容顶不住。SG90 堵转 ~1A。

### ⚠️ 星形接地

舵机的地**不要**串到逻辑区的地上。单独走粗线回到 **J1 的 GND 脚**
（也就是全板的星形接地点），逻辑地单独一路回到同一点。

舵机电流不走这条规矩的话，地电位会被抬起几百 mV，表现为
**随机复位、屏幕闪烁、按键误触发**。详见 `DESIGN.md` §9.1。

| 母座高度 | **8.5mm** | §3.5 |
| BAT 焊盘极性 | 背面朝上、Type-C 朝上时 **左− 右+** | §3.3 |
| 连接器线序 | **模块正面朝自己**，左→右 `GND, 3V3, SCL, SDA, K4, K3, K2, K1` | §6 |
| **BAT 焊盘间距** | **2.5mm**（中心距） | §3.4 |

### 9.2 还没定（按代价从大到小排）

| # | 事项 | 怎么定 | 错了会怎样 |
|---|---|---|---|
| 1 | **电池带不带保护板**（§2.1） | 看引线上有没有小 PCB | 裸电芯过放鼓包，再充**起火** |
| 2 | **保护板过流点**（§2.1） | 问卖家 | 舵机一堵转就整板断电 |
| 3 | **顶针筒径**（§3.4） | 卡尺量实物 | 2.5mm 中心距下选粗了容易连锡 |
| 4 | **TPS61088 的 Vref 与反馈电阻**（§5.1） | 按数据手册算，别用我记的 | 5V 轨电压不对，舵机行程变小或烧 |
| 5 | **电池尺寸和容量** | 实物 | 决定板子尺寸，画完才发现装不下 |
| 6 | **舵机型号** | 铭牌 | 决定 boost 电流，MG996R 级要重算 §2 |
| 7 | **XIAO 天线净空区**（DESIGN.md §9.2） | 必须画进板框 | 忘了的话无线基本废掉 |

### 9.3 装机时的检查（不挡打样，但**插电前**必须做）

| 事项 | 怎么做 | 错了会怎样 |
|---|---|---|
| **顶针有没有连锡**（§3.4） | 焊完量 `TP1→TP2` 电阻，应 **~200kΩ** | 读 0Ω = `BAT+`/`BAT−` 短路 → **起火** |
| **JST 座极性**（§2.3） | 蜂鸣档对 J1 和电池引线 | **起火** |
| **顶针极性 + 接触**（§3.3） | 插 USB、**不接电池**，量 `TP1→TP2` 应为 **+4.2V** | 负值 = 顶针接反；0V = 没压上 |
| **连接器方向**（§6） | 蜂鸣档确认模块的 GND 通到 J3 的 1 脚 | 插反 = `3V3` 和 `GND` 对调，**烧** |

> 本表所有内容是纸面推导，**没有任何一项在实机上验证过**。
> 尤其是 §3 的顶针——**它是这一版唯一没有现成先例可以直接照抄的部分**
> （官方扩展板用了同样的原理，但尺寸是配它自己那块板的）。
> `DESIGN.md` §12 建议第一版就只打电源+顶针这一小块，先把它验掉。
