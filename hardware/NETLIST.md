# 网络表

配合 `DESIGN.md` 使用。这份表用来在嘉立创EDA Pro 里录入连接。

## 怎么用这份表

**不要照着拉线。** 在嘉立创EDA 里更快的做法是：

1. 从立创库放好元件
2. 给每个引脚**贴网络标签**（放置 → 网络标签），标签名照抄本表的「网络名」
3. 同名标签自动连成一个网络，不用画长线
4. 最后用「设计 → 检查」看有没有漏连

这样画出来的图可读性也更好——电源和地靠标签，只有局部才拉线。

> **引脚号以立创库里的符号为准。** 本表给的是**引脚功能名**
> （VIN / SW / FB / BAT 这种），不是引脚序号。
> 我手上没有这些芯片的数据手册，凭记忆写序号很可能错，而那比不写更糟。
> 符号里的引脚名和本表一致，对照着贴就行。

## 2. 12V 输入与保护

| 网络名 | 连接 | 说明 |
|---|---|---|
| `DC_IN` | J1.正 | DC-005 电源座 |
| `DC_IN` | F1.1 | 自恢复保险丝 2A |
| `12V_RAW` | F1.2, Q1.D, D1.K | 保险丝之后、防反接之前 |
| `GND` | J1.负, D1.A, Q1.G, C1.−, C2.2 | |
| `VM_12V` | Q1.S, C1.+, C2.1, U1.VIN, U8.VM | 受保护的 12V |

- **Q1 防反接**：P-MOS，**源极朝负载侧**（S 接 `VM_12V`，D 接 `12V_RAW`，
  G 接 `GND`）。接反时 Vgs=0 管子截止，体二极管反向阻断。
  接对时体二极管先导通，随后 Vgs=−12V 把管子完全打开。
- **D1**：TVS 钳位，阴极接 `12V_RAW`、阳极接 `GND`。

## 3. 5V 主轨（buck）

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VM_12V` | U1.VIN, C3.+, C4.1 | buck 输入 |
| `GND` | U1.GND, C3.−, C4.2, C5.−, C6.2, R2.2 | |
| `SW1` | U1.SW, L1.1, Cbst.2 | 开关节点，**铜面积要小** |
| `BST1` | U1.BST, Cbst.1 | 自举电容，跨在 BST 和 SW 之间 |
| `5V_DC` | L1.2, C5.+, C6.1, R1.1, U1.FB(经R1) | buck 输出 |
| `FB1` | U1.FB, R1.2, R2.1 | 反馈分压中点 |

**输出电压设定**：`Vout = Vref × (1 + R1/R2)`，Vref 以 MP2315 数据手册为准
（我记的是 0.8V，**打样前请核对**）。目标是 **5.15V**，比 boost 的 5.00V 略高，
这样 DC 在时由 buck 独占输出。

**EN 脚**：接 `VM_12V` 使能（或经分压，按数据手册的 EN 阈值算）。

## 4. 电池与充电

### 4.1 ⚠️ 这一节请照参考设计接，不要照我写的接

锂电池保护接错会**起火**。我给的是**拓扑和网络名**，
逐脚接法请照下面其中之一，我有意不凭记忆写具体接法：

- **方案 A（推荐，最省事）**：买**自带保护板的软包电池**（引出线多一块小 PCB）。
  这样板上只要充电电路，不需要 DW01A + 8205A。
- **方案 B**：照 TP4056 官方数据手册的「典型应用电路」，
  外加 DW01A + FS8205A 的官方典型电路。
  市面上「TP4056 充电保护模块」的原理图就是这两张图拼起来的，可以对照。

**先确认你手上的软包电池带不带保护板**，这决定要不要画 §4.2。

### 4.2 充电与保护（仅方案 B 需要）

| 网络名 | 连接 | 说明 |
|---|---|---|
| `5V_DC` | U2.VCC | 充电输入 |
| `GND` | U2.GND, R3.2, U2.TEMP | TEMP 不用时接地 |
| `VBAT` | U2.BAT, BT1.+, U5.VIN | 电池正极 |
| `PROG` | U2.PROG, R3.1 | R3 定充电电流 |

**充电电流**：`I = 1200 / R3`（R3 单位 kΩ，结果单位 A）。
建议 **500mA → R3 = 2.4kΩ**（第一版保守些，发热小一半）。
`CHRG` / `STDBY` 接 LED 指示，各自串限流电阻。

### 4.3 5V 升压（电池供电路径）

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VBAT` | U5.VIN, C7.+ | boost 输入 |
| `GND` | U5.GND, C7.−, C8.2, C9.−, R5.2 | |
| `SW2` | U5.SW, L2.1 | |
| `5V_BAT` | L2.2, C9.+, R4.1 | boost 输出，**设定 5.00V** |
| `FB2` | U5.FB, R4.2, R5.1 | |

目标是 **5.00V**，比 buck 的 5.15V 略低，让 DC 在时 buck 独占。

### 4.4 ⚠️ 5V 汇流：两个源怎么合

```
5V_DC ──[Q2 理想二极管]──┬── VM_5V
5V_BAT ─[Q3 理想二极管]──┘
```

| 网络名 | 连接 | 说明 |
|---|---|---|
| `5V_DC` | Q2.A | 阳极朝 5V_DC |
| `VM_5V` | Q2.K, Q3.K, C10.+, C11.1 | 汇流点 |
| `5V_BAT` | Q3.A | |

- **不要用肖特基**（见 DESIGN.md §3.4）：3A 下压降 0.5V，
  会把 VM_5V 打到 4.4V，低于舵机 4.8V 下限，还发热 1.5W。
  用 P-MOS 理想二极管（LTC4412 之类控制器，或分立 P-MOS + 比较器）。
- **不需要 DC 存在检测**——靠 5.15V / 5.00V 的压差自动选高的那个。
  buck 在时 Q2 导通、Q3 反偏；DC 一掉，Q3 立刻接管（boost 一直开着，
  没有启动延迟）。代价是 DC 在时 boost 空载耗电池 1~2mA，可忽略。

## 5. 3.3V 逻辑

**不自己做 3.3V。** 直接用 XIAO 的 `3V3` 脚带 OLED（约 20mA，毫无压力）。

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VM_5V` | D2.A | 隔离二极管阳极 |
| `XIAO_5V` | D2.K, U6.5V | 见下方警告 |
| `3V3` | U6.3V3, U7.VCC | XIAO 输出 |
| `GND` | U6.GND, U7.GND | |

### ⚠️ D2 不能省

XIAO 的 5V 脚和它自己的 USB VBUS 是连通的。不加 D2 的话，
**插 USB 调程序时 USB 的 5V 会反灌进 VM_5V**——而那里挂着舵机和步进。
轻则电脑 USB 口限流，重则烧口。

D2（SS14）阳极朝 `VM_5V`、阴极朝 `XIAO_5V`，USB 电流出不去。

> 用 XIAO 自己的 LDO 还有个好处：不用管 3.3V 的时序，
> 也不会出现「我们的 3.3V 和 XIAO 的 3.3V 打架」。

> **❗需要你确认：屏幕模块一共引出几根线？**
> 你现在的按键是屏幕模块自带的（固件注释里写的是「屏幕 K1」），
> 那这个连接器就是 **8 针**（电源2 + I2C2 + 按键4）。
> 如果按键其实是独立的一块小板，那就是两个 4 针连接器。
> 这个必须确认——连接器针数画错，板子直接报废。

## 7. 舵机

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VM_5V` | J2.红, C12.+, C13.1 | |
| `GND` | J2.棕, C12.−, C13.2 | |

## 8. 步进（预留，只留接口）

| 网络名 | 连接 | 说明 |
|---|---|---|
| `VM_12V` | U8.VM, C14.+, C15.1 | 驱动功率级 |
| `GND` | U8.GND, C14.−, C15.2 | |
| `VM_5V` | U8.VDD | 逻辑供电 |
| `STEP` | U8.STEP, U6.D6 | |
| `DIR` | U8.DIR, U6.D7 | |
| `EN` | U8.EN, U6.D9 | |
| `MOTOR_A1/A2/B1/B2` | U8 → J3 | 4 根，见下 |
| `LIMIT` | J4.1, U6.D10；J4.2 → `GND` | 限位开关 |

- **U8 用 16P StepStick 母座**，不焊死驱动芯片。
  A4988 / DRV8825 / TMC2209 都是这个尺寸，想用哪个插哪个。
- **VM 接 12V，意味着拔掉 DC 后步进不工作**（电池只有 3.7V，A4988 最低 8V）。
  这是取舍，见 DESIGN.md §5。
- ⚠️ **A4988 的限流电位器必须先在空载下调好再插电机**，否则可能烧电机。
  这条要写进丝印。

## 10. 打样前必须确认的

1. **屏幕模块引出几根线**（§6）——决定连接器针数，画错就废板
2. **软包电池带不带保护板**（§4.1）——决定要不要画 DW01A + 8205A
3. **XIAO 插座的物理引脚顺序**——我没有离线资料可查，
   建议直接在立创库里搜「XIAO ESP32C6」，用现成的符号和封装，
   别自己按 GPIO 顺序摆
4. MP2315 / TPS61088 的 **Vref 和反馈电阻取值**——按数据手册算，别用我记的
5. **XIAO 天线净空区**（DESIGN.md §6.3）——必须画进板框
