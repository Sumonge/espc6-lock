# espc6-lock

纯倒计时**时间锁**固件，无密码。跑在 Seeed XIAO ESP32C6 上，用 SSD1315 128x64 OLED
显示，靠舵机拨动一个机械锁舌。

```
空闲(开锁) --K3--> 倒计时中(锁定) --归零--> 空闲(开锁)
```

## ⚠️ 设计前提：这不是安全设备

**计时状态不做持久化。** 上电一律回到「空闲 = 开锁位」，也就是说拔电重启就能绕过锁定。
舵机因此是 fail-open 的：掉电、复位、固件崩溃，锁都是开的。

这是刻意的选择——本设备的定位是**定时器**，不是锁具。要真正防拆，得加上
状态存 NVS + 上电先回锁定位，那样又会引入「电池耗尽后永久锁死」的问题。
在改这个语义之前，别把它用在任何有实际安全含义的场合。

## 硬件

| 元件 | 型号 |
|---|---|
| 主控 | Seeed XIAO ESP32C6 |
| 显示 | SSD1315 128x64 I2C OLED（0.96"），板上带 K1~K4 四个按键 |
| 执行器 | 舵机 + 机械拨片/锁舌 |

### 接线

| 屏幕/外设 | 接到 XIAO | GPIO |
|---|---|---|
| GND | GND | — |
| **VCC** | **3V3** | — |
| SCL | D5 | 23 |
| SDA | D4 | 22 |
| K1 | D0 | 0 |
| K2 | D1 | 1 |
| K3 | D2 | 2 |
| K4 | D3 | 21 |
| 舵机 信号 | D8 | 19 |
| 舵机 VCC | **外部 5V 电源** | — |
| 舵机 GND | 外部电源 GND，**并与 XIAO 共地** | — |

> **屏幕 VCC 必须接 3.3V，不能接 5V。**
>
> **舵机不要从 XIAO 的 5V 脚取电。** 舵机堵转电流轻松上到几百 mA，会拉垮
> XIAO 的供电导致反复重启。用独立 5V 电源，且 GND 必须和 XIAO 共地，
> 否则 PWM 信号没有参考电位，舵机会乱抖。

## 操作

### 桌面

上电后先是 1.5 秒的启动画面，然后进桌面。

```
┌────────────────────────────┐
│ 已锁        ▁▃▅▇     ▭      │  ← 状态栏：锁状态 / 信号 / 电量
├──────────┬──────────┬──────┤
│   锁图标  │  地球    │ 齿轮 │
│   定时    │  网络    │ 设置 │  ← K1/K2 移选中框，K3 进入
├──────────┴──────────┴──────┤
│                            │  ← 留空
└────────────────────────────┘
```

| 按键 | 作用 |
|---|---|
| K1 | 选中框**向右**移一格 |
| K2 | 选中框**向左**移一格 |
| K3 | 进入选中的应用 |
| K4 | 回桌面（单击或双击都行） |

到最右边再按 K1 会绕回最左边，反过来也一样。

**状态栏里只有「锁状态」（已锁／开锁）是真的**，它跟着定时锁应用走。
信号和电量画的是**空心**，意思是「还读不到」——不是「信号为零」也不是
「电池没电」。信号要等 WiFi 功能，电量还缺一颗电量计芯片。宁可看着像占位，
也不画成实心让人误以为电量是 0。

三个应用：

- **定时** —— 定时锁，见下面几节
- **网络** —— 设备名 + 无线／配网状态（后两项还没做，显示「未接入」）
- **设置** —— 关于本机

### 设备名

网络页第 2 行显示的 `LM-XXX-XXX` 是**上电随机起一次、之后固定不变**的名字
（6 个随机位，每位是 0-9 或 A-Z，共 36⁶ ≈ 22 亿种，不会重名）。它存在 NVS
里，拔电重启也不会变。

想让它重新起名（或者要把板子当成新的一块），得**擦掉整块 Flash**：

- Arduino IDE：`工具 → Erase All Flash Before Sketch Upload → Enabled`，
  然后正常上传一次（对应 boards.txt 里的 `menu.EraseFlash`）
- 命令行：用 `esptool.py erase_flash`（`arduino-cli` 本身**没有** erase
  子命令，只有 `burn-bootloader`）

⚠️ 这一步会把**整个 NVS** 一起擦掉 —— 现在只有设备名，等 WiFi 凭据做出来
之后，配过的网也会一起没。

### 定时锁：待机（开锁，正在设时长）

| 按键 | 作用 |
|---|---|
| K1 | 时长 + |
| K2 | 时长 − |
| K3 | 启动倒计时 → 上锁 |
| K4 | 归零重设 |

加减有两种方式：

- **单击** 1 分钟
- **按住** 自动连发，步进随按住时长变大（避免设 2 小时要按 120 下）
  - 按住 < 2 秒 → 每次 1 分钟（精确调节）
  - 按住 2~5 秒 → 每次 5 分钟
  - 按住 > 5 秒 → 每次 15 分钟
- **双击** 直接跳 1 小时。这一档刻意不参与连发加速——1 小时是「双击」这个
  离散动作换来的，要 3 小时就双击 3 次。

时长上限 1440 分钟（24 小时）。

### 倒计时中（锁定）

**长按 K4 满 5 秒**才能取消。刻意不用「按下就取消」，否则一碰就解锁了。

按住期间画面会切成紧急解锁界面：第 1 段变「紧急解锁中」，第 2、3 段是
脚丫 + 羽毛动画（羽毛随按住时长向右飘），第 4 段是一条两端圆角的胶囊
进度条——空轨道是描边，走过的部分实心填充。

### 解锁提示（取消成功 / 倒计时归零后 5 秒）

第 1 段是「已取消」或「已解锁」，第 2、3 段是一把锁：锁体不动，锁梁绕
左腿根部向左转 90° 躺平，0.7 秒转完（缓出曲线），之后一直停在打开状态。
第 4 段写「手动取消 拨片已打开」或「时间到  拨片已打开」。

锁梁转轴在左腿根部而不是正中——真锁就是这么开的，左腿始终插在锁体里
当铰链。所以它转到底时会横躺在锁体内部、从左壁穿出 2px，这是刻意的。

这一屏**不显示大号 `00:00:00`**：它要传达的是「锁开了」，不是「时间归零了」。

## 屏幕布局（定时锁应用）

定时锁占据整屏，128x64 横向四等分，每段 16px：

```
┌────────────────────────────┐
│ 第 1 段  标题／状态         │  ← 下面一条分隔线
├────────────────────────────┤
│                            │
│ 第 2+3 段  大号 HH:MM:SS    │  ← 跨两段显示，共 32px
│                            │
├────────────────────────────┤
│ 第 4 段  提示               │  ← 待机时留空
└────────────────────────────┘
```

秒数总是 `:00`——时长只能按整分钟设定。

## 编译与烧录

依赖 **U8g2**（Arduino IDE 库管理器搜 "U8g2"）。舵机用板载 LEDC 直接产生
50Hz PWM，不需要 Servo 库。

命令行（`arduino-cli` 随 Arduino IDE 2.x 一起装）：

```bash
CLI="/c/Program Files/Arduino IDE/resources/app/lib/backend/resources/arduino-cli.exe"

# 编译
"$CLI" compile --fqbn esp32:esp32:XIAO_ESP32C6 --warnings all .

# 烧录（端口自己换，用 "$CLI" board list 查）
"$CLI" upload -p COM5 --fqbn esp32:esp32:XIAO_ESP32C6 .
```

用 IDE 的话直接选板子 `XIAO_ESP32C6` 然后点上传即可，不需要额外设置。

开串口监视器（115200）能看到按键日志、状态迁移和每 5 秒一行的心跳。
**开机时会做按键体检**：把四个按键脚配成 `INPUT_PULLUP` 后读一次空闲电平，
没按时必须是 HIGH；哪个脚开机就是 LOW，说明它被短路到 GND 了，多半是接线问题。

## 首次装好后必须标定

`SERVO_US_UNLOCK` / `SERVO_US_LOCK` 两个脉宽（默认 1000 / 2000 µs）是按常见
舵机给的估值，**没有在实机上验证过**。装上拨片后按实际行程调：

- 数值调大 → 往一个方向多转，调小 → 往反方向多转
- 舵机在某个位置发出持续「吱吱」声或发热，说明顶到机械限位了，
  把对应数值往中间调 50~100 µs

## 版本控制

仓库：<https://github.com/Sumonge/espc6-lock>（私有）

首次推送时用的（`gh` 已登录的前提下，一条命令建仓库 + 关联 + 推送）：

```bash
gh repo create espc6-lock --private --source=. --remote=origin --push
```

没有 `gh` 时的等价手动流程：

```bash
# 1. 网页上建空仓库。关键：不要勾 README/.gitignore/LICENSE，
#    否则远程先有一个提交，跟本地历史对不上，首次 push 会被拒。
git remote add origin git@github.com:Sumonge/espc6-lock.git
git push -u origin main
```

> 如果第 1 步不小心勾了，`git push` 会报 `rejected (fetch first)`，用
> `git pull --rebase origin main` 把远程那个提交垫到本地历史下面，再 push。

日常循环：

```bash
# 改完 .ino 先编译确认能过，再提交
git add -A
git commit -m "把脚丫镜像成左脚"
git push
```

remote 走 SSH（`git@github.com:...`），`gh` 的登录走 HTTPS token，两者互不干扰。
换台机器 clone 时要么把 `~/.ssh/id_ed25519` 带过去，要么改用 HTTPS 地址 + PAT。

## 文件

固件是**多文件**的 `.ino`。Arduino 会把它们拼成**一个编译单元**：主文件
（和文件夹同名）排最前，其余**按字母序**跟在后面。

| 文件 | 说明 |
|---|---|
| `espc6-lock.ino` | 主文件：配置区、按键、舵机、设备名、应用表、K4 整形、启动画面、setup/loop |
| `app.h` | 框架与各应用之间**唯一**的共享头文件 |
| `app_desktop.ino` | 桌面：状态栏 + 一行三格图标 |
| `app_lock.ino` | 定时锁应用（本文件其余几节讲的就是它） |
| `app_net.ino` | 网络应用（设备名 + 无线/配网状态，后两项还没做） |
| `app_settings.ino` | 设置应用（暂时只有「关于」页） |
| `icons.ino` | 桌面图标点阵（16x16，低位在左） |
| `ui_kit.ino` | 各应用共用的绘制工具 |
| `CLAUDE.md` | 给 AI 助手看的项目约定与踩坑记录 |
| `tools/` | 版面几何验证脚本，见下 |
| `hardware/` | 原理图与网络表 |
| `.gitattributes` | 统一 LF 换行 |

`tools/` 里两个脚本是**改版面之前必须先跑**的——屏幕上的字和格子到底装不
装得下，全靠它们量，不靠目测：

| 脚本 | 作用 |
|---|---|
| `python tools/desktop_sim.py` | 桌面逐像素模拟 + 几何自检（越界 / 重叠 / 标签装不装得下）。`gen` 生成图标点阵，`full` 打印整屏，`bar` 看状态栏各种取值 |
| `bash tools/fontcheck/run.sh` | 用**真字模**量文字宽度和墨迹高度（在主机上编译 U8g2 自己的源码，和固件是同一份） |
